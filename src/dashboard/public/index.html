Live Peer Ranking

Ranked by First Seen % (how often a peer delivers a new block first, out of the blocks it was around for) - not raw counts, so a peer connected for a long time doesn't automatically outrank a newer one with a better rate. Only currently connected peers are shown here - manage manually-trusted peers (online or not) in the Manual Peers panel below. "Add as Manual" re-tests the peer's host on ports 8333/9333 itself before adding it - it never trusts whatever port the peer happened to be observed on (important for inbound peers, whose visible port is just a temporary outbound source port). If the peer is currently connected inbound, it still gets queued so it reconnects automatically once that inbound connection eventually drops.

Manual Peers

Peers you've explicitly trusted, online or not. Bitcoin Core only actively maintains a limited number of these at once (see slot count above) - extras stay queued and connect automatically once a slot frees up. There's no separate "Disconnect" here on purpose: as long as a peer is still trusted, Core just reconnects it right back, so "Remove" (forgets the peer AND drops the current connection) is the only action that does anything meaningful.
